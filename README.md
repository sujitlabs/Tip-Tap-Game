# Tip Tap Game

A small browser game where you click the red circle to increase your score. After every click, the circle moves to a random position on the screen.

## Run locally

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Click the red circle and try to build your score.

## Project files

- `index.html` — game layout and score display
- `style.css` — page and circle styling
- `script.js` — scoring and random circle movement

## Technologies

HTML, CSS, and vanilla JavaScript.
